# ドキュメント

プロジェクトのドキュメントをこのフォルダに格納します。
必要になった時点でMarkdownファイルを追加してください。

## 記載方針

- ルートのREADMEには、プロジェクト概要、現在の利用方法、起動・停止・テストの基本手順を記載します。
- Issueごとの実装経緯、判断理由、遭遇した問題と対応、検証結果、未完了事項は`docs/issues/`に記載します。
- 作業記録は`issue-<番号>-<概要>.md`という名前で作成し、対象Issueと記録日を明記します。実施済み・未確認・未実施を区別し、後から確認した結果は日付を添えて追記します。
