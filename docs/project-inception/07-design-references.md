# 07. UIデザインの参考資料と画像利用方針

## 参考にしたサイト

- **サイト:** scmGalaxy
- **記事:** [Complete Guide of Prometheus with Grafana](https://www.scmgalaxy.com/tutorials/complete-guide-of-prometheus-with-grafana-certification-courses-tutorials-and-training/)

- **参考にした要素:** Prometheus/Grafanaの監視ダッシュボードの見た目、CPU・メモリなどの監視指標をまとめて見せるUIの方向性。

## このプロジェクトでの位置づけ

このサイトの画像は、開発テーマの選定とUIイメージの検討時に**参考として閲覧した資料**である。記事や画像の著作者・権利者による本プロジェクトへの使用許諾を意味しない。

- 記事内の画像は**ダウンロードしてGitHubリポジトリに転載しない**。
- 出典URLを記載すること自体は、画像の複製・再配布の許可を得ることとは異なる。
- 参考画像そのものをアプリの成果物・完成イメージとして扱わない。
- このプロジェクト用の新しい完成イメージ画像は**作成しない**。
- 実装するUIは、[02-implementation.md](02-implementation.md)の要件に基づき独自に作成する。

掲載画像の再利用については、画像ごとのライセンスや権利者からの許可を別途確認する必要がある。参照先: [scmGalaxy Terms and Conditions](https://www.scmgalaxy.com/about/terms-and-conditions/)。

本資料では参考リンクのみを記録し、記事画像は同梱しない。
